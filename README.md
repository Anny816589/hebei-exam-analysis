# 河北省考岗位数据分析

分析河北省考近三年（2024–2026）岗位数据，回答选岗问题。

## 数据来源
- 河北省人事考试网 / 中公等机构汇总的岗位表

## 项目目标
- 梳理计算机类岗位 vs 三不限岗位的竞争比差异
- 跟踪张家口、石家庄等目标地市的招录量变化
- 辅助应届生选岗决策

## 技术栈
- Python（pandas / matplotlib）
- SQL
- BI 工具（待定）
